# Security policy

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability, leaked
credential, authentication bypass, or customer data exposure.

Use the repository's private GitHub security advisory flow or contact the
GrapeCity security team through the security contact configured in the
official repository settings.

## Secrets

MCP keys are credentials. Do not commit them to this repository, include them
in screenshots, or paste them into issues and pull requests. If a key is
exposed, revoke it and request a replacement immediately.
