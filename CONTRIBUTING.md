# Contributing

Thanks for helping improve the GrapeCity MCP catalog.

## Pull requests

- Keep each pull request focused on one metadata or documentation change.
- Update `server.json` and the matching server README together.
- Never include real MCP keys, customer data, or private service details.
- Run `npm run check` before opening the pull request.
- Explain any endpoint, authentication, version, or marketplace change in
  the pull request description.

Maintainers may request product, documentation, security, or legal review
before merging a public-facing change.
